Restablecer contraseña

Este sistema no tiene servidor propio, así que no puede cambiar automáticamente la contraseña de otra persona — eso solo se puede hacer desde la consola de Firebase. Para restablecer la de —: entra a Firebase console → Authentication → Users, busca este correo (cópialo con el botón) y usa "Reset password" desde ahí.
